# הזמנה לחתונה

דף בודד, בלי שרת ובלי תלויות: `wedding/index.html`.
הכתובת החיה: `https://shopshain6-sys.github.io/wedding/`

## איפה משנים את הפרטים

כל הפרטים יושבים באובייקט אחד בשם `CONFIG`, בתחילת ה-`<script>` שבתחתית הקובץ.
משנים שם את הערכים ושומרים — אין צורך לגעת בעיצוב.

| שדה | מה הוא עושה |
| --- | --- |
| `nameA`, `nameB` | שמות החתן והכלה בכותרת |
| `sealLetters` | האותיות שעל חותם השעווה שבמעטפה |
| `dateISO` | התאריך והשעה. מזין את הספירה לאחור ואת קובץ היומן. אזור זמן ישראל: `+03:00` בקיץ, `+02:00` בחורף |
| `dateText`, `dayText`, `hebrewDateText` | התאריך כפי שהוא מוצג לאורחים |
| `inviteLine` | שורת ההזמנה שבתוך הלב (אפשר `<br />`) |
| `venue` | שם האולם, כתובת והערה. ה-`lat`/`lng` מזינים את המפה המשובצת ואת כפתורי הניווט; בלעדיהם המפה מוסתרת והניווט נבנה לפי הכתובת |
| `schedule` | סדר היום — אפשר להוסיף ולהוריד שורות |
| `rsvp.phone` | המספר שאליו נשלח אישור ההגעה בוואטסאפ, בפורמט `972501234567` |
| `gift.iplan` | הקישור ל-iPlan. זה הכפתור הראשי בקטע המתנה |
| `gift.bit` / `gift.paybox` | קישורים ישירים. אם אין, אפשר למלא `gift.phone` והמספר יוצג ככפתור העתקה |
| `gift.bank` | שם המוטב, בנק, סניף וחשבון — כל שדה שממולא מופיע עם כפתור העתקה |

## קישורים שימושיים

- `?to=דנה` — ממלא מראש את שם המוזמן בטופס אישור ההגעה, לשליחה אישית.
- `#open` — נכנסים ישירות להזמנה בלי אנימציית פתיחת המעטפה.

## תצוגה מקדימה בוואטסאפ

`og.png` היא התמונה שנשלחת עם הקישור. אם משנים שמות, תאריך או אולם —
צריך ליצור אותה מחדש, אחרת הקישור ימשיך להראות את הפרטים הישנים.

## הערות

- הדף מסומן `noindex` כדי שלא יופיע בתוצאות החיפוש של גוגל.
- כל האנימציות מכבדות את ההגדרה "הפחתת תנועה" של מערכת ההפעלה.
